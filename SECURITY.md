# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities, credentials, or sensitive data in public Issues. Use GitHub's private vulnerability reporting if enabled, or contact the maintainer through the repository's private security channel.

## Scope

Security-sensitive areas include tool authorization, external actions, memory integrity, provenance, model-provider credentials, sandbox escape, collective-message validation, and resource exhaustion.

Never commit API keys, access tokens, passwords, private keys, or personal data.
