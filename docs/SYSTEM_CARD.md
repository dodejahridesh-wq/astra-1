# Astra-1 System Card

## Demonstrated in v0.1
Deterministic end-to-end cognitive loop; explicit memory stores; world-model events; verification; governance gating; skill evaluation; provenance-tagged collective packets; telemetry.

## Not demonstrated
Consciousness, sentience, biological life, general intelligence, frontier-level reasoning, unrestricted autonomy, or self-directed reproduction.

## Safety posture
External or irreversible actions require human approval. Candidate skill evolution is sandboxed.
