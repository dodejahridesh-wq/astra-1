# Astra-1 Roadmap

- V0.1 deterministic cognitive core — implemented.
- V0.2 durable persistence and service API — implemented for execution history, ordered traces, episodic memory, world-model snapshots/events, durable goals, task state, resumability, governance modes, and the local HTTP service.
- V0.3 real model adapters, stronger retrieval, and independent verification — next major runtime frontier.
- V0.4 richer skill sandbox, simulation namespaces, multimodal perception, and expanded resource-aware execution.
- V0.5 multi-instance collective protocol with transport, conflict resolution, and stronger provenance exchange.
- Research frontier: specialized models trained around measured cognitive workloads.

The roadmap is deliberately subordinate to the implementation status. A feature is considered implemented only when the repository contains the behavior, tests, and documentation needed to support that claim.
