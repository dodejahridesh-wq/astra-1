# GitHub Growth Setup

GitHub recommends using a clear README, license, contribution guidance, topics, social preview, security features and community features to make public repositories understandable and discoverable.

## One-time owner actions

1. Add 8–15 precise repository topics such as `artificial-intelligence`, `ai-agents`, `cognitive-architecture`, `memory`, `reasoning`, `ai-research`, `machine-learning`, `open-source`, `python`, `agent-architecture`.
2. Upload a 1280×640 social-preview image with the Astra-1 identity and one clear sentence.
3. Enable Discussions for research conversations.
4. Enable Dependabot alerts, secret scanning/push protection and code scanning where available.
5. Enable GitHub Pages using `/docs` as the publishing source if desired.
6. Create the first release after the initial test suite is green.
7. Add Astra-1 to the maintainer's GitHub profile README.

## Outreach cadence

Publish useful artifacts, not repetitive promotion: demos, benchmark results, architecture notes, failure reports, contributor tasks and release notes.

Use the launch draft and social-copy library in `docs/LAUNCH_POST.md` and `marketing/SOCIAL_COPY.md`.
