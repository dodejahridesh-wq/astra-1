# Contributor Map

Astra-1 is intentionally modular so contributors can work on focused research areas.

| Area | Example work |
|---|---|
| Memory | retrieval, consolidation, forgetting, provenance |
| World model | entities, causal hypotheses, uncertainty |
| Executive | goals, planning, resource allocation |
| Verification | independent checks, evidence graphs |
| Metacognition | uncertainty and failure detection |
| Skills | sandboxed acquisition and benchmarking |
| Simulation | counterfactuals and future-state modeling |
| Governance | permissions, approvals, auditability |
| Collective | multi-instance protocols and trust |
| Evaluation | cognitive benchmarks and regressions |
| UI | research console and trace visualization |
| Infrastructure | persistence, providers, APIs, deployment |
