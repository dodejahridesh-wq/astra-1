# Why Astra-1?

Scaling a model improves the substrate. Astra-1 asks a different systems question: what architecture should surround a capable model if we want persistence, inspectability, verification, reusable skills, and controlled adaptation?

The project is therefore intentionally model-agnostic. A model can be replaced without replacing the organism architecture.

This separation is a research hypothesis, not a claim that architecture alone solves intelligence or safety.
